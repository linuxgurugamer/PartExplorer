PartExplorer is a utility mod for Kerbal Space Program 1 which allows you to browse, filter, inspect and compare the parts that are installed in your game; it shows the loaded part database in a searchable and sortable table together with thumbnails, filters for mods and categories, integration with the editor filter, detailed information about the parts and rotating previews. It is able to display data for stock modules, resources, science information, SCANsat data and configurable information from supported science mods.

It is possible to choose parts for side-by-side comparison, with the option to hide rows that are identical, to highlight the differences, to mark numeric values that are low or high, and to display the deltas between the parts. The PartExplorer program also features customizable Details and Compare sections, a summary page for loaded mods, the ability to insert parts directly into the VAB/SPH, and right-click actions that allow parts to be added to the editor or comparison list as well as the copying of part IDs or paths. The program is designed to be useful both when playing the game normally and when developing or troubleshooting modded installations.
